# content-broadcasting-system
broadcasting system for school for principal, teachers and students

# live deployment checkout
[content broadcasting system](https://content-broadcasting.netlify.app/)

# How to setup locally
Step1 - create folder and run below command
 https://github.com/vermashobhit1994/content-broadcasting-system.git
It will download all files from github repository to current directory.
 
Step2 - install pnpm globally
npm install -g pnpm

Step3 - install packages using pnpm
pnpm install
