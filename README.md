# Introduction 
This is content broadcasting system for school with below requirements
1. Login and Logout for teacher and principal with authentication and authorisation.
2. uploading content for teacher and approving by principal.
3. live checking of broadcast content for students by teacher and principal.
4. dashboard for teacher and principal.

# live deployment checkout link
[content broadcasting system](https://content-broadcasting.netlify.app/)

# How to setup locally
Step1 - create folder and run below command

git clone https://github.com/vermashobhit1994/content-broadcasting-system.git

It will download all files from github repository to current directory.

Step2 - install node using official website

[node installer](https://nodejs.org/en/download)
 
Step3 - install pnpm globally

npm install -g pnpm

Step4 - install packages using pnpm

pnpm install

Step5 - run development server 

pnpm run dev

Step6 - open browser and type

http://localhost:3000

you'll see application
